# Dispatch a docs synchronization

Identify the implementation evidence, governing AGENTS instructions, affected
documentation subtree, audit refresh requirements, and link/validator gate.
Dispatch one scope-disjoint brief per repository or ownership subtree; never
grant a docs brief source-code globs. Ask the runner to distinguish observed
behavior from planned behavior and to update required audit inventories.

Use Fabric agent intent, not Loom shell control. Never copy tokens or secrets
into documentation or task evidence.
